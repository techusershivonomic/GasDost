Upload customer list

Any Excel or CSV works — for example the customer report from the HPCL or BPCL portal, with its own columns. The console finds the name, mobile, address and consumer number by itself and shows you a preview; change a column if it guessed wrong, then press Save customers. Or use the template below. When the console shows 🟢 Online (top right), customers are saved in the online database — safe even if this browser is cleared, and the same on every office computer. They can be searched in Bookings and Send links. Uploading again updates customers already saved (matched by mobile number) and adds the new ones.

Columns: Name, Mobile Number, First Address, Dealer Name. Name and Mobile Number are required, the rest can be left blank. The Unique code is given automatically when you save — C0001, C0002 and so on — and a customer keeps the same code for good.

🧹 Duplicate customers

After uploading an oil-company report, the same person can appear twice — the old record (older mobile, no consumer no.) and the new one from the report. Same name + similar address is treated as the same person: the old record moves to the 🗑 Recycle bin (can be restored for 30 days). Same name with a different address is only listed for you to check.

Want it fully automatic?

The one-tap queue above costs nothing and works today. Proper hands-off broadcasting needs the official WhatsApp Business API, which is a real step up:

  • A Meta Business account with your business verified, and a phone number given over to the API — that number can no longer use the normal WhatsApp app
  • Message wording submitted to Meta for approval before you may send it, usually a day or two
  • A small server to hold the API key — it cannot live in this page, because anyone could read it and send messages as you
  • A per-message fee. Indian providers such as AiSensy, Interakt, Gupshup or Wati wrap all of the above in a simpler dashboard for a monthly fee
  • Bulk SMS is a similar story in India — a gateway like MSG91 or Fast2SMS, plus DLT registration with TRAI for your sender ID and every message template, and a few paise per message. The per-customer SMS button above needs none of that, because your own phone sends it

Worth it once you are sending hundreds a day. Below that, the queue above is usually the better trade. The Export to Excel button gives you exactly the columns those providers ask for, so nothing is wasted if you move later.
